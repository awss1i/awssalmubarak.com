## Never Translated

These stay exactly as written in every language:

- awssalmubarak.com, Awss Al-Mubarak, GitHub, GitHub Pages, Python, MIT
- the theme names violet, slate and nordic
- DOM, CSS, SVG, URL, JSON, PR
